# `inspect.json` schema

`inspect.schema.json` is generated from `config::Config` (and the types it composes)
via `schemars` — see `config::run_schema`. It is not auto-regenerated by CI; after
changing a field or doc comment on `Config`/`Check`/`ArchitectureConfig`/etc., refresh
it with:

```bash
cargo run -- schema --out schema/inspect.schema.json
```
